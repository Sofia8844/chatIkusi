# Objetivo
Quiero crear una aplicación web moderna llamada **IkusAI Chat** usando React, TypeScript, Vite y TailwindCSS.
El diseño base es el HTML que adjunto más abajo, el cual quiero que se transforme completamente en componentes React funcionales escritos en TypeScript.

Además, necesito que se genere la configuración completa para crear una **imagen Docker de producción** que sirva la aplicación (multi-stage build) y un `docker-compose.yml` para desarrollo y producción.

# Stack técnico
- React 18 con TypeScript
- Vite
- Tailwind CSS configurado en modo JIT
- Dark Mode activado con la clase `dark`
- Estructura modular con tipado fuerte en los props de cada componente
- Docker multi-stage para producción (build -> nginx)
- docker-compose para desarrollo (servir con vite) y producción (servir con nginx)

# Requerimientos (resumen)
1. Proyecto base (TypeScript):
   ```
   npm create vite@latest ikusai-chat -- --template react-ts
   cd ikusai-chat
   npm install
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   ```
   y configurar Tailwind según la documentación oficial.

2. Tailwind config:
   - Incluir los colores y temas definidos en mi HTML.
   - Usar `darkMode: "class"`.

3. Estructura del proyecto:
   ```
   src/
   ├── components/
   │   ├── Sidebar.tsx
   │   ├── ChatHeader.tsx
   │   ├── ChatMessage.tsx
   │   ├── MessageInput.tsx

   ├── types/
   │   ├── chat.ts
   ├── App.tsx
   ├── main.tsx
   └── index.css
   ```

4. Tipos e interfaces:
   Crear `src/types/chat.ts` con las interfaces `ChatMessageProps` y `ChatHistoryItem`.

5. Componentes:
   - Tipados con `React.FC<...>` o `FC`.
   - `MessageInput` debe recibir `onSend(message: string): void`.
   - `ChatMessage` debe soportar `isAI` para alternar estilos (AI vs user).
   - Mantener gradientes y estilos originales.

6. Dark mode:
   - Toggle manual y preferencia del sistema (usar `useEffect` para añadir `dark` si corresponde).

7. Build & Run scripts:
   En `package.json` incluir scripts recomendados:
   ```json
   "scripts": {
     "dev": "vite",
     "build": "vite build",
     "preview": "vite preview --port 4173",
     "lint": "eslint . --ext .ts,.tsx",
     "format": "prettier --write ."
   }
   ```

8. Typescript strict:
   Sugerir `"strict": true` en `tsconfig.json`.

# Docker (lo que debe generar)
Generar **automáticamente** los siguientes archivos en la raíz del proyecto:

1. `Dockerfile` (multi-stage, recomendado):
   - Stage 1: node:18-alpine -> instalar deps, build (`npm ci` y `npm run build`).
   - Stage 2: nginx:stable-alpine -> copiar `dist` a `/usr/share/nginx/html`, configurar `nginx.conf` para no cachear `index.html` y habilitar gzip.
   - Añadir `HEALTHCHECK` que haga `curl --fail http://localhost:80/ || exit 1`.
   - Etiquetar puerto `EXPOSE 80`.

   Ejemplo (incluir en el prompt para que Codex lo genere exactamente):
   ```
   # -- Dockerfile --
   FROM node:18-alpine AS builder
   WORKDIR /app
   COPY package*.json ./
   RUN npm ci
   COPY . .
   RUN npm run build

   FROM nginx:stable-alpine AS production
   RUN apk add --no-cache curl
   COPY --from=builder /app/dist /usr/share/nginx/html
   COPY docker/nginx.conf /etc/nginx/conf.d/default.conf
   EXPOSE 80
   HEALTHCHECK --interval=30s --timeout=5s --start-period=5s --retries=3 CMD curl -f http://localhost/ || exit 1
   CMD ["nginx", "-g", "daemon off;"]
   ```

2. `docker/nginx.conf` (configuración simple para Vite build):
   ```
   server {
     listen 80;
     server_name _;
     root /usr/share/nginx/html;
     index index.html;
     location / {
       try_files $uri $uri/ /index.html;
     }
     gzip on;
     gzip_types text/plain application/json text/css application/javascript text/xml application/xml application/xml+rss text/javascript;
     add_header Cache-Control "no-cache, no-store, must-revalidate";
     add_header Pragma "no-cache";
     add_header Expires "0";
   }
   ```

3. `.dockerignore`:
   ```
   node_modules
   dist
   .git
   .env
   .env.local
   .DS_Store
   ```

4. `docker-compose.yml` con dos servicios:
   - `app-dev`: usa la imagen node:18, monta el código, expone 5173 y ejecuta `npm run dev` (Vite).
   - `app-prod`: construye la imagen usando el Dockerfile y expone 80.

   Ejemplo:
   ```
   version: '3.8'
   services:
     app-dev:
       image: node:18-alpine
       working_dir: /app
       volumes:
         - ./:/app
         - /app/node_modules
       ports:
         - "5173:5173"
       command: sh -c "npm install && npm run dev -- --host 0.0.0.0"

     app-prod:
       build:
         context: .
         dockerfile: Dockerfile
       ports:
         - "80:80"
       restart: unless-stopped
   ```

5. Instrucciones para construir y ejecutar la imagen:
   - `docker build -t ikusai-chat:latest .`
   - `docker run -p 80:80 ikusai-chat:latest`
   - O usar `docker-compose up --build` para producción.
